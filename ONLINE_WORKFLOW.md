# Online-first workflow (browser-based)

Once this repo is pushed to GitHub and Pages is set to "GitHub Actions", you can edit and deploy without local setup.

## Edit
- GitHub Web Editor: press the dot key in the repo
- Or use GitHub Codespaces

## Deploy
- Push to main (or master)
- GitHub Actions builds and deploys dist/ to GitHub Pages automatically

## One-time GitHub setting
- Repo Settings > Pages > Source: GitHub Actions

## App base path
- Vite base is set to: /radiology-ai-viewer/
